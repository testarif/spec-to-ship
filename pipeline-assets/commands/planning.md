# Plan the implementation

Use the `planning-and-task-breakdown` workflow. Read `SPEC.md` and the current project context. Create a dependency-ordered plan of small, vertically sliced tasks. Every task must state its outcome, acceptance criteria, and verification steps. Prefer complete user-visible paths over horizontal layers; identify checkpoints and risks.

Write `tasks/plan.md` and a matching checkbox list to `tasks/todo.md`. Do not overwrite unrelated or incomplete existing work; this is a fresh generated workspace, so treat any conflicting artifacts as an assumption to document rather than silently discarding them. This pipeline is autonomous: do not ask for approval; keep the plan consistent with the spec and proceed.
